# Smart Gym - AdminPanel Workspace

This workspace contains the **AdminPanel** application for Smart Gym Management & Fitness Tracker.

👉 **For complete project overview and setup instructions, see the main WebFrontend workspace:**
- Location: `../smart-gym-management--fitness-tracker-21010-21052/README.md`

## Quick Start (This Workspace)

```bash
cd AdminPanel
npm install
npm start
```

Opens at http://localhost:3001

## About AdminPanel

The admin panel provides role-based management capabilities:
- User and trainer management
- Content and workout plan management  
- System settings and configuration
- Audit logs and compliance
- Role-based access control (5 role types)

## Preview Mode

The admin panel runs in mock mode by default with sample data. No backend setup required!

📖 [Detailed Preview Guide](./AdminPanel/PREVIEW.md)

## Role Types

Try logging in with different roles to see access control:
- **superadmin**: Full system access
- **admin**: User/trainer management
- **trainer_manager**: Trainer-specific features
- **content_admin**: Content management
- **auditor**: View-only audit access

For more details, see the [main README](../smart-gym-management--fitness-tracker-21010-21052/README.md).
